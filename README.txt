# Arash English — Professional Website

## Files
- index.html — homepage
- grammar.html — A1/A2 grammar lessons with Persian translations
- vocabulary.html — A2 vocabulary with Persian meanings/examples
- exercises.html — 30+ challenging interactive questions
- about.html — About Arash section
- style.css — responsive professional design
- script.js — lessons, vocabulary, quiz and navigation

## Upload to GitHub
1. Open your `arash-english` repository.
2. Click **Add file → Upload files**.
3. Select all files in this folder.
4. If GitHub says files already exist, allow the new files to replace them.
5. Scroll down and click **Commit changes**.
6. Wait a few minutes for GitHub Pages to redeploy.
7. Refresh your website.

Old files with different names will remain. After checking the new site, delete old files that are no longer used.

## Important
Keep `index.html` in the repository root because it is the homepage for GitHub Pages.
